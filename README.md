# Sky毕业设计管理系统前端

基于 Vue 3、TypeScript、Vite、Element Plus、Vue Router、Pinia 和 Axios 构建的管理端前端。

## 已实现页面

- 登录页：对接后端 Cookie 会话登录。
- 首页：展示当前用户信息与实时账号统计。
- 用户管理：支持筛选、分页、新增、编辑和删除用户，仅管理员可访问。
- 课题管理：学生浏览和申请课题，教师维护并提交本人课题，管理员审核课题。
- 选题管理：学生查看和取消本人申请，教师审核本人课题的选题，管理员查看全部记录。
- 任务书管理：教师为已通过选题创建、编辑和下发任务书，学生查看已下发内容，管理员归档查询。
- 过程文档：学生分阶段提交文档并保留版本，教师审核最新版本，管理员查看全部记录。
- 答辩分组：管理员维护答辩组、教师和学生名单，教师与学生查看本人答辩安排。
- 文件上传：所有角色均可多选上传图片、PDF、DOC、DOCX，并复制访问地址。
- 个人主页：支持查看账号信息、上传头像，以及修改本人姓名和所属院系。
- 整体布局：顶部导航、左侧可收起侧边栏、中间内容区、底部信息栏和移动端适配。

## 本地运行

默认将 `/api` 代理到 `http://localhost:8080`。如需修改后端地址，编辑 `.env.development` 中的 `VITE_API_TARGET`。

```powershell
npm install
npm run dev
```

生产构建：

```powershell
npm run build
```
